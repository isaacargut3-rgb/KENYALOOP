# Contributing

1. Branch from `main`; open a pull request (protect `main` and require review).
2. Reference SRS requirement IDs in commits/PRs (e.g. `LIST-08`).
3. Don't build deferred scope (payments/escrow, biometrics, safety scores) without a change-log entry.
4. Definition of done: validated inputs, accessible markup (labels, keyboard, contrast), no secrets in code, tests/manual checks noted in the PR.
5. Keep verification badge wording in the `VERIFY` constant; never add a generic "verified" label, and never let subscription status affect badges.
