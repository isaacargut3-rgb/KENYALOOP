# NyumbaLoop brand guide (from Brand & Implementation Proposal v2.0)

**Name:** NyumbaLoop. *Nyumba* (Kiswahili: home) + *Loop* (a connected, repeatable search journey). Working name only: KIPI register clearance, domain and social-handle checks are required before public launch.
**Tagline:** Find. View. Move in.
**Promise:** A clearer, more accountable way to find a place to live.
**Product principle:** Accurate listings. Accountable advertisers. Clear information. Safer house hunting.

## Colours (implemented as CSS tokens in `style.css`)
| Role | Hex | Use |
|---|---|---|
| Navy (primary) | `#123047` | Text, hero, footer CTA |
| Teal (secondary) | `#087E83` | Buttons, links, "Loop" in wordmark |
| Gold (accent) | `#F0B43C` | Calls to action, featured ribbon (always with navy text for contrast) |
| Coral (supporting) | `#E76F51` | Sparingly: alerts, highlights |

Typography: proposal specifies Aptos or a modern rounded sans-serif. The prototype uses Nunito (headings) and Inter (body) with Aptos in the fallback stack.

## Assets

Logo status: concept mark for discussion; not a registered trademark. Review for distinctiveness before filing.

## Voice
Clear, respectful, locally aware, honest, helpful. Use plain language for deposit, service charge, viewing and verification.
